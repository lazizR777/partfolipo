# Lazizbek Risqulov – Frontend Developer Portfolio

Toshkentdagi frontend dasturchining shaxsiy portfolio veb-sayti.

## Tarkibi
- `index.html` – Asosiy veb-sahifa, dizayn, animatsiyalar va interaktiv funksiyalar.
- `robots.txt` – Qidiruv tizimlari uchun sozlama.
- `sitemap.xml` – Sayt xaritasi.
- `.gitignore` – Git repozitoriyasiga ortiqcha fayllarni qo‘shmaslik qoidalari.

## GitHub’ga joylash
1. Arxivni ochib, ichidagi barcha fayllarni GitHub repozitoriyangizga yuklang.
2. Jonli havolada ochish uchun **Settings → Pages** bo‘limida `main` branch va `/ (root)` ni tanlang.
